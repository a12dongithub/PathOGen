# Miscellaneous retained data

This directory isolates data-like material whose schema or provenance is not yet
sufficient for a canonical dataset location. Nothing here is an approved source
for a new experiment until documented and promoted through a manifest.

- `tcga_10k_cached_tensors/`: legacy `.pt` activation/feature caches.
- `nuhtc_demo/`: separated third-party demo WSI, patch, annotation, and output data.
- `os_metadata/`: retained operating-system metadata moved out of scientific folders.
